# 全站极光背景 + 鼠标互动光效 — 设计规格

日期：2026-07-27
状态：已获用户批准

## 背景与目标

网站为苹果风浅色主题（白底、品牌蓝 `#0071e3`），用户反馈视觉"太平淡"，希望全站增加有科技感的"光污染"氛围效果。

经讨论确定的方向：

- 保持现有浅色主题，叠加柔和辉光（不改深色）
- 效果形式：漂浮极光光斑 + 鼠标互动
- 配色：蓝、紫、粉多彩极光
- 实现方案：CSS 渐变光斑 + 少量 JS（非 Canvas/WebGL）

## 范围

- 全站所有页面生效：通过共享的 `assets/css/main.css` 与 `assets/js/main.js` 实现，所有页面均已引用这两个文件，无需改动任何 HTML
- 不影响现有 SEO 结构、翻译系统、布局与可读性

## 设计细节

### 结构

- `main.js` 在 DOM ready 时动态创建 `<div class="aurora-bg">` 并插入 `body` 最前，内含 3 个 `<i>` 光斑元素（蓝/紫/粉）
- 光斑：`radial-gradient` 圆形渐变 + `filter: blur()` 柔边，`position: fixed` 覆盖视口，`z-index: -1`，`pointer-events: none`

### 漂浮动画

- 每个光斑一个独立的 CSS `@keyframes`（位移 + 缩放 + 透明度微变）
- 周期错开：18s / 24s / 30s，无限循环，营造随机游动感

### 鼠标互动

- `mousemove`（节流）将视口坐标写入 `--mx` / `--my` CSS 变量
- 光斑位移 = 外层 `animation`（漂浮）+ 内层基于鼠标距离的 `calc()` 偏移（近者偏移大，呈"被吸引"感）
- 偏移经 CSS `transition` 平滑，天然惯性；鼠标静止或离开后缓缓回位
- 触屏设备（`@media (hover: none)`）：不绑定鼠标事件，仅保留漂浮

### 强度与可读性

- 光斑透明度 15–25%，普通叠加（不用混合模式），白底上呈淡水彩光晕
- 光效层级永远在内容之下，不影响文字可读性

### 无障碍与性能

- `prefers-reduced-motion: reduce`：关闭动画与鼠标跟随，光斑静态低透明度显示或隐藏
- 动画仅使用 `transform` / `opacity`（GPU 合成层），不触发重排

## 改动文件

| 文件 | 改动 |
|---|---|
| `assets/css/main.css` | 新增极光背景样式（约 80 行） |
| `assets/js/main.js` | 新增创建光斑 + 鼠标跟踪逻辑（约 40 行） |

## 验收标准

1. 全站所有页面背景出现蓝/紫/粉三团缓慢漂移的柔和光斑
2. 鼠标移动时附近光斑被轻微吸引，带惯性平滑
3. 白底下文字可读性不受影响
4. 触屏设备无鼠标跟随、仅漂浮；`prefers-reduced-motion` 下动画关闭
5. 无需改动任何 HTML 文件；`file://` 直接打开也正常
